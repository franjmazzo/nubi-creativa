Arquitectura general

El sitio es una Single Page Application estática sin framework ni bundler. Todo el código reside en index.html. El único componente server-side es la Netlify Function para el chatbot.

Frontend (index.html)
  • CSS inline (~1300 líneas)
  • HTML semántico (~500 líneas)
  • JavaScript vanilla (~900 líneas)
  • GSAP 3.12.5 (CDN)
  • ScrollTrigger (CDN)
  • Google Fonts (CDN)
  • Fuentes locales (Sniglet, Source Serif 4)
Backend (Netlify Functions)
  • Node.js Lambda serverless
  • @anthropic-ai/sdk (npm)
  • Ruta: /.netlify/functions/chat
  • Método: POST
  • Variables de entorno: ANTHROPIC_API_KEY
Deploy (Netlify)
  • Git push → auto-deploy
  • Directorio raíz como publish dir
  • npm install automático (SDK)
  • CORS headers en netlify.toml
Repositorio (GitHub)
  • github.com/franjmazzo/nubi-creativa
  • Branch principal: master
  • .gitignore: .env, node_modules, .netlify

Sistema de internacionalización (i18n)

El sistema i18n es completamente custom, sin librerías externas. Soporta ES y EN con actualización en tiempo real al cambiar idioma.

Estructura de datos

// Objeto global de traducciones (~línea 1750 del script)
const translations = {
  es: {
    "hero.sub": "No hacemos solo diseño...",
    "services.design.title": "Diseño Gráfico",
    // ...
  },
  en: {
    "hero.sub": "We don't just design...",
    "services.design.title": "Graphic Design",
    // ...
  }
};

Atributos HTML para i18n

AtributoEfectoEjemplo
data-i18n="clave"Reemplaza textContent<p data-i18n="hero.sub">
data-i18n-html="clave"Reemplaza innerHTML (permite tags)<h2 data-i18n-html="about.statement">
data-i18n-placeholder="clave"Reemplaza atributo placeholder<input data-i18n-placeholder="contact.form.name">
data-i18n-label="clave"Reemplaza aria-labelBotones con solo ícono

Función applyTranslations()

function applyTranslations() {
  const t = translations[currentLang] || translations.es;

  document.querySelectorAll('[data-i18n]').forEach(el => {
    const key = el.dataset.i18n;
    if (t[key]) el.textContent = t[key];
  });

  document.querySelectorAll('[data-i18n-html]').forEach(el => {
    const key = el.dataset.i18nHtml;
    if (t[key]) el.innerHTML = t[key];
  });
  // ... (placeholder, label)

  // Actualizar título y meta description de la página
  if (t['page.title']) document.title = t['page.title'];
}

Función setLang()

function setLang(lang) {
  currentLang = lang;          // Variable global
  applyTranslations();
  // Actualiza aria-pressed de los botones ES/EN
  // Hero headline se re-anima
}

// IMPORTANTE: setLang es decorado por initChatbot() e initProjectModal()
// para sincronizar sus propios textos. Cada decorador llama al anterior,
// formando una cadena: setLang → chatbot → modal → applyTranslations
Cadena de decoradores de setLang Si añadís un nuevo componente que necesite actualizarse al cambiar idioma, seguí el mismo patrón: guardá la referencia al setLang actual, creá tu propio wrapper que llame al anterior, y asignalo a window.setLang.

Variable global currentLang

let currentLang = 'es'; // Inicializada al top del script

// Acceso desde cualquier función:
const lang = typeof currentLang !== 'undefined' ? currentLang : 'es';

Sistema de animaciones

El sitio usa dos sistemas de animación en paralelo: CSS puro para elementos simples y GSAP 3 para secuencias complejas.

1. CSS Reveal (scroll)

Cualquier elemento con clase .reveal se anima al entrar en el viewport via IntersectionObserver:

/* CSS */
.reveal { opacity: 0; transform: translateY(32px); transition: opacity 0.7s, transform 0.7s; }
.reveal.in-view { opacity: 1; transform: none; }

/* JS — initScrollReveal() */
const observer = new IntersectionObserver((entries) => {
  entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('in-view'); });
}, { threshold: 0.12 });

document.querySelectorAll('.reveal, .reveal-right').forEach(el => observer.observe(el));

2. GSAP Hero (initHeroAnimations)

Al cargarse la página, el hero se anima en secuencia escalonada:

gsap.from('#hero-eyebrow', { opacity: 0, y: 20, duration: 0.7, delay: 0.3 });
gsap.from('#hero-line-1',  { opacity: 0, x: -30, duration: 0.8, delay: 0.5 });
gsap.from('#hero-line-2',  { opacity: 0, x:  30, duration: 0.8, delay: 0.65 });
gsap.from('#hero-sub',     { opacity: 0, y: 20, duration: 0.7, delay: 0.9 });
gsap.from('#hero-ctas',    { opacity: 0, y: 20, duration: 0.7, delay: 1.05 });

3. GSAP ScrollTrigger (initGSAP)

Parallax en las shapes del hero y stagger en las tarjetas de proyectos:

gsap.to('.shape-1', {
  y: -140, ease: 'none',
  scrollTrigger: { trigger: '#hero', start: 'top top', end: 'bottom top', scrub: 1.5 }
});
// Las project-cards usan GSAP en lugar del sistema reveal CSS
gsap.to('.project-card', {
  opacity: 1, y: 0, stagger: 0.08, duration: 0.65, ease: 'power3.out',
  scrollTrigger: { trigger: '#projects-grid', start: 'top 80%', once: true }
});

4. Cursor personalizado (initCursor)

El cursor custom tiene un dot (8px) y un ring (36px). En elementos interactivos (.hoverable, a, button) el ring escala a 56px.

5. Partículas y meteoros (canvas)

initParticles() dibuja puntos flotantes en un <canvas> con requestAnimationFrame. initMeteors() genera divs CSS con animación de entrada diagonal. Ambos se pausan fuera del viewport para no consumir CPU innecesariamente.

6. Tilt 3D (initTilt)

Las service cards tienen efecto de inclinación 3D al mover el mouse. Se calculan las coordenadas relativas del mouse respecto al centro del elemento y se aplica rotateX / rotateY via style.transform.

Sistema de modal de proyectos

El modal de proyectos es un bottom-sheet fullscreen que se desliza desde abajo. No usa routing: actualiza el hash de la URL con history.replaceState.

Estructura del DOM del modal

  <div class="pm-backdrop"></div>       <!-- Fondo semitransparente -->
  <div class="pm-sheet">                 <!-- Sheet que sube -->
    <div class="pm-handle"></div>       <!-- Drag handle (decorativo) -->
    <div class="pm-header">...</div>    <!-- Nav ←/→ + botón X -->
    <div class="pm-body">               <!-- Área scrolleable -->
      <div class="pm-hero">...</div>   <!-- Banner + título -->
      <div class="pm-content">...</div> <!-- Descripción + meta + chips -->

Chatbot — Netlify Function

Arquitectura serverless

Browser: fetch POST /.netlify/functions/chat
↓
Netlify Edge: enruta a la función Lambda
↓
chat.js: valida body, sanitiza mensajes
↓
Anthropic API: claude-haiku-4-5-20251001
↓
Respuesta JSON: { reply: "..." }

Contrato de la API (chat.js)

// REQUEST
POST /.netlify/functions/chat
Content-Type: application/json
{
  "messages": [
    { "role": "user",      "content": "¿qué servicios ofrecen?" },
    { "role": "assistant", "content": "Ofrecemos..." }
  ],
  "lang": "es"   // "es" | "en"
}

// RESPONSE (200)
{ "reply": "Respuesta del chatbot..." }

// RESPONSE (error)
{ "error": "API error" }

Seguridad y límites en chat.js

  • Solo acepta método POST (405 en cualquier otro)
  • Máximo 20 mensajes por request (los últimos 20 si hay más)
  • Cada mensaje se trunca a 2000 caracteres
  • El role se fuerza a "user" o "assistant" (no se confía en el cliente)
  • La API Key nunca sale del servidor (variable de entorno de Netlify)

Límites en el cliente (initChatbot)

  • maxlength="500" en el input del chat
  • El historial en memoria se mantiene en máximo 20 mensajes
  • isLoading bloquea envíos concurrentes

Guía de extensión

Agregar una nueva sección al sitio

  1. Agregar el HTML de la sección con un id único (ej: <section id="equipo">).
  2. Agregar el link en <ul class="nav-links"> y en el mobile menu.
  3. Agregar las claves de texto en translations.es y translations.en.
  4. Agregar el CSS en el bloque <style>, antes de los @media.
  5. Si la sección tiene animaciones de scroll: agregar clase .reveal a los elementos.
  6. Actualizar el scroll spy en initScrollSpy() si se quiere highlight en nav.

Agregar un nuevo idioma

  1. Agregar un nuevo bloque en translations: pt: { ... }
  2. Agregar el botón en el lang toggle: <button class="lang-btn" data-lang="pt">PT</button>
  3. El sistema existente detecta automáticamente el data-lang y llama a setLang().

Reemplazar el hero de texto por video

<!-- En lugar de .retro-grid y canvas, agregar: -->
<video class="hero-video" autoplay muted loop playsinline>
  <source src="assets/hero-video.mp4" type="video/mp4">
</video>

/* CSS */
.hero-video {
  position: absolute; inset: 0; width: 100%; height: 100%;
  object-fit: cover; opacity: 0.4;
}

Integrar un formulario de contacto real

El formulario actual hace validación client-side pero no envía datos. Para conectarlo:

Opción A — Netlify Forms (más simple)

Agregar data-netlify="true" al <form>. Netlify intercepta el POST automáticamente.

Opción B — Netlify Function propia

Crear netlify/functions/contact.js que reciba el formulario y use un servicio de email (SendGrid, Resend, etc.).

Agregar Google Analytics

<!-- Antes de </head> en index.html -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXX');
</script>
Performance El sitio no usa bundler. Cada script externo (GSAP, Google Fonts) agrega una request HTTP. Si el rendimiento se vuelve crítico, considerar: self-hosting de GSAP, usar font-display: swap (ya configurado), y agregar un Service Worker para cache.
