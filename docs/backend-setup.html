1. Arquitectura del backend

El backend de Nubi Creativa usa Netlify Functions (serverless Node.js) como capa de API. No hay servidor propio — todo se ejecuta como funciones Lambda directamente en Netlify. La base de datos es Supabase (PostgreSQL gratuito) y los emails se envían vía Resend (API REST, sin paquetes npm extra).

Funciones creadas

ArchivoRutaDescripción
contact.js/.netlify/functions/contactRecibe el formulario de contacto, valida, aplica rate limiting y envía emails vía Resend
projects.js/.netlify/functions/projectsDevuelve proyectos publicados desde Supabase (GET público, cacheado 60s)
admin.js/.netlify/functions/adminCRUD completo para proyectos, protegido con x-admin-secret
chat.js/.netlify/functions/chatProxy para la IA Nubi (Anthropic Claude) — ya existía

Panel de administración

En /admin/index.html hay un panel CMS independiente. El acceso está protegido por la clave ADMIN_SECRET. Permite agregar, editar, eliminar y reordenar proyectos con contenido bilingüe (ES/EN).

Flujo de datos

  1. Al cargar el sitio, renderProjectCards() renderiza la grilla con los datos estáticos de respaldo (PROJECTS).
  2. Luego, loadProjects() hace fetch a /.netlify/functions/projects.
  3. Si hay datos en Supabase, reemplaza la grilla con los proyectos del CMS.
  4. El formulario de contacto envía a /.netlify/functions/contact, que valida, guarda y envía emails.

2. Configurar Supabase

Supabase provee una base de datos PostgreSQL gratuita con API REST automática, perfecta para este caso de uso.

1

Crear proyecto en supabase.com → New Project. Elegí una región cercana (São Paulo o US East).

2

Ejecutar el schema SQL: en el dashboard ir a SQL Editor → New Query. Pegar el contenido completo de config/supabase-schema.sql y hacer clic en Run.

El script crea las tablas projects, rate_limits y contact_submissions, configura Row Level Security y agrega los 6 proyectos de demo.
3

Obtener las claves: en el dashboard ir a Settings → API. Copiar:

  • Project URL → valor para SUPABASE_URL
  • anon / public key → valor para SUPABASE_ANON_KEY
  • service_role key → valor para SUPABASE_SERVICE_KEY (mantenerla secreta)
⚠ Importante: La service_role key bypasea Row Level Security. Nunca exponerla en el frontend — solo se usa en las Netlify Functions del lado del servidor.

3. Configurar Resend (emails)

Resend es un servicio de email transaccional con una API REST simple y plan gratuito (3000 emails/mes). No requiere paquetes npm — se llama con fetch().

1

Crear cuenta en resend.com → Add API Key. Copiar la clave generada.

2

Verificar dominio (opcional pero recomendado): en Resend → Domains → Add Domain. Agregar el registro DNS indicado en el proveedor de dominio. Esto permite usar noreply@nubicreativa.com como remitente.

Sin dominio verificado, los emails salen desde onboarding@resend.dev — funciona para pruebas pero no se puede usar en producción para el cliente final.
3

Una vez verificado el dominio, configurar la variable RESEND_FROM con el remitente deseado:

RESEND_FROM=Nubi Creativa <hola@nubicreativa.com>

5. Desarrollo local

Netlify CLI ejecuta las funciones localmente con hot reload, replicando el entorno de producción.

1

Instalar Netlify CLI (una sola vez, globalmente):

npm install -g netlify-cli
2

Instalar dependencias:

npm install   # instala @anthropic-ai/sdk
3

Crear el archivo .env en la raíz del proyecto con las variables del apartado anterior.

4

Iniciar el servidor local:

netlify dev

El sitio queda disponible en http://localhost:8888. Las funciones responden en http://localhost:8888/.netlify/functions/.

Nota: netlify dev carga automáticamente el archivo .env de la raíz del proyecto.

Probar las funciones

# GET proyectos
curl http://localhost:8888/.netlify/functions/projects

# POST formulario de contacto
curl -X POST http://localhost:8888/.netlify/functions/contact \
  -H "Content-Type: application/json" \
  -d '{"name":"Test","email":"test@test.com","message":"Hola, quiero más info."}'

# GET admin (reemplazar con tu ADMIN_SECRET)
curl http://localhost:8888/.netlify/functions/admin \
  -H "x-admin-secret: tu-contrasena"

6. Deploy en Netlify

1

Conectar repositorio: en el dashboard de Netlify hacer clic en Add new site → Import an existing project. Seleccionar el repositorio de GitHub.

2

Configurar el build: Netlify detecta automáticamente el netlify.toml. Verificar que:

  • Publish directory: . (raíz)
  • Functions directory: netlify/functions (ya configurado en netlify.toml)
3

Agregar las variables de entorno: en el dashboard de Netlify ir a Site settings → Environment variables → Add variable. Agregar todas las variables del apartado 4.

4

Desplegar: hacer clic en Deploy site. Netlify ejecuta npm install automáticamente para instalar el SDK de Anthropic.

5

Verificar: acceder al sitio desplegado y probar el formulario de contacto, el chatbot y la carga dinámica de proyectos.

⚠ Nunca commitear .env. El archivo .gitignore ya lo excluye. Las variables de entorno solo se configuran en el dashboard de Netlify.

7. Panel de administración CMS

El panel se encuentra en /admin (ej: https://nubicreativa.com/admin).

Acceso

  1. Navegar a https://nubicreativa.com/admin
  2. Ingresar el valor de ADMIN_SECRET configurado en Netlify
  3. La sesión se guarda en sessionStorage hasta que se cierra el navegador o se hace clic en "Salir"

Gestión de proyectos

OperaciónCómo hacerla
Crear proyectoClic en "+ Nuevo proyecto". Completar Slug, Categoría, Gradiente y los contenidos en ES e EN. El slug debe ser único (ej: mi-nuevo-proyecto).
Editar proyectoClic en "Editar" en la fila del proyecto. Modificar los campos y guardar.
ReordenarUsar los botones ↑ ↓ en la columna "Orden". El orden se guarda automáticamente.
Publicar / borrradorEn el formulario de edición, desmarcar "Publicado" oculta el proyecto del sitio sin eliminarlo.
EliminarClic en "Eliminar". Se pide confirmación. Esta acción es permanente.

Gradiente CSS

El campo "Gradiente" acepta cualquier valor CSS válido para background. Se puede previsualizar en tiempo real en el formulario.

-- Ejemplos de gradientes
linear-gradient(135deg, #0f1c35 0%, #1a4a7a 100%)
linear-gradient(135deg, #0d1b2a 0%, #1f67b0 100%)
linear-gradient(135deg, #1a0d2e 0%, #2d1b50 100%)

Seguridad del admin

  • El HTML del panel es de acceso público, pero no puede hacer nada sin la clave correcta
  • Todas las operaciones de escritura/lectura requieren el header x-admin-secret
  • La función admin.js usa SUPABASE_SERVICE_KEY que solo existe en el servidor
  • Para mayor seguridad se puede agregar autenticación de Netlify Identity en el futuro

Rate limiting del formulario de contacto

Máximo 3 envíos por IP por hora. Las IPs se almacenan hasheadas (SHA-256 + salt) en la tabla rate_limits de Supabase. Pasada la hora, el contador se reinicia automáticamente.

Para limpiar registros viejos manualmente:

-- Limpiar registros de rate limiting de más de 2 horas
DELETE FROM rate_limits WHERE created_at < NOW() - INTERVAL '2 hours';
