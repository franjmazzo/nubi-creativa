Estructura del sitio

El sitio web de Nubi Creativa es una Single Page Application (SPA): todo el contenido vive en un único archivo index.html. No hay base de datos ni panel de administración — los cambios se hacen editando directamente el código y subiendo a GitHub.

Archivos del proyecto

Archivo / CarpetaQué contiene
index.htmlTodo el sitio: CSS, HTML y JavaScript en un solo archivo
netlify/functions/chat.jsFunción serverless que conecta el chatbot con la API de Claude
netlify.tomlConfiguración de Netlify (directorio de funciones, headers CORS)
package.jsonDependencias Node.js (SDK de Anthropic para el chatbot)
.envVariables de entorno locales — nunca se sube a GitHub
assets/Imágenes, logos y fuentes tipográficas
docs/Esta documentación

Secciones del sitio

02

Actualizar textos

El sitio es bilingüe (ES/EN). Todos los textos visibles están centralizados en el objeto translations dentro del <script> del archivo index.html, cerca de la línea 1750.

Cómo encontrar un texto

1
Abrí index.html en un editor de texto (VS Code recomendado).
2
Usá Ctrl+F para buscar el texto que querés cambiar, o buscá su clave (ej: "hero.sub").
3
Vas a encontrar dos entradas: una en el bloque es: { ... } y otra en en: { ... }. Editá ambas.

Ejemplo: cambiar el subtítulo del hero

// Buscá en el objeto translations:
es: {
  "hero.sub": "No hacemos solo diseño — construimos marcas...",
  // ↑ Reemplazá este texto
},
en: {
  "hero.sub": "We don't just design — we build brands...",
  // ↑ Y su equivalente en inglés
},

Claves principales de texto

ClaveDónde aparece
hero.eyebrowTexto pequeño arriba del título ("Agencia Creativa · Buenos Aires")
hero.subPárrafo debajo del título principal
about.statementFrase grande de la sección Nosotros
about.descPárrafo descriptivo de la sección Nosotros
services.design.descDescripción del servicio Diseño Gráfico
contact.titleTítulo de la sección Contacto
footer.descDescripción breve en el footer
footer.copyrightTexto de copyright (actualizar el año)
Tip Si un texto aparece en el HTML con el atributo data-i18n="clave", significa que ese elemento usa el sistema de traducciones. Editá solo el objeto translations, no el HTML directamente.
Nubi Creativa — Guía de Usuario Sección 3 · Proyectos
03

Gestionar proyectos

Los proyectos tienen dos capas: las tarjetas del portfolio (HTML) y los detalles del modal (JavaScript). Hay que actualizar ambas.

Editar un proyecto existente

Buscá el array const PROJECTS = [ en el script. Cada proyecto tiene esta estructura:

{
  slug: 'nombre-unico-sin-espacios',
  gradient: 'linear-gradient(135deg, #color1, #color2)',
  es: {
    tag: 'Diseño',
    title: 'Nombre del proyecto',
    description: 'Descripción larga del proyecto...',
    client: 'Nombre del cliente',
    year: '2025',
    duration: '4 semanas',
    deliverables: ['Entregable 1', 'Entregable 2']
  },
  en: { /* misma estructura en inglés */ }
},

Agregar una imagen de fondo al modal

Por defecto los modales usan degradados CSS. Para usar una imagen real:

1
Copiá la imagen a assets/projects/nombre-imagen.jpg
2
En el objeto del proyecto, cambiá gradient por: image: 'assets/projects/nombre-imagen.jpg'
3
En la función populate(), agregá lógica para usar background-image si existe p.image.

Agregar un nuevo proyecto

1
Agregar la tarjeta HTML: Copiá un bloque <article class="project-card"> existente en la sección #proyectos y actualizá la categoría (data-category) y los textos.
2
Agregar datos al array PROJECTS: Copiá un objeto existente y completá con la info del nuevo proyecto.
3
Verificar el orden: El modal asocia cada tarjeta con su posición en el DOM. El primer proyecto en el HTML corresponde al primer objeto del array, y así sucesivamente.
Importante El orden de los proyectos en el HTML debe coincidir exactamente con el orden en el array PROJECTS. Si agregás un proyecto en medio del HTML, también insertalo en la misma posición del array.

05

Deploy y Netlify

El sitio se despliega automáticamente en Netlify cada vez que se sube (push) código a GitHub. No hay pasos manuales de compilación.

Flujo de trabajo para actualizar el sitio

1
Editá los archivos localmente (en tu computadora).
2
Guardá los cambios y verificá en el navegador abriendo index.html localmente.
3
Subí a GitHub con los comandos: 
git add index.html
git commit -m "descripción del cambio"
git push
4
Netlify detecta el push y re-despliega automáticamente en 1–2 minutos.

Configurar la API Key del chatbot

Solo necesario la primera vez o si cambiás la clave La API Key nunca debe estar en el código. Vive únicamente en el panel de Netlify.
1
Ingresá a netlify.com → tu sitio → Site configuration → Environment variables.
2
Hacé click en Add a variable.
3
Nombre: ANTHROPIC_API_KEY · Valor: tu clave de Anthropic (empieza con sk-ant-).
4
Guardá y volvé a hacer deploy: Deploys → Trigger deploy → Deploy site.

Verificar que el deploy fue exitoso

  • Entrá al panel de Netlify → Deploys. Si el último deploy tiene ícono verde ✓, está listo.
  • Si hay un error, hacé click en el deploy fallido para ver el log.
  • Error más común: Cannot find module '@anthropic-ai/sdk' → verificá que package.json esté incluido en el repositorio.
Chatbot funcionando correctamente cuando: El botón de chat (esquina inferior izquierda) responde mensajes sobre los servicios de Nubi Creativa en menos de 3 segundos.
Nubi Creativa — Guía de Usuario Sección 6 · Chatbot
06

Chatbot Nubi IA

El chatbot está integrado en la esquina inferior izquierda del sitio. Usa la API de Claude (Anthropic) para responder preguntas sobre los servicios de la agencia.

Qué puede responder el chatbot

  • Información sobre los 5 servicios de Nubi Creativa
  • Cómo es el proceso de trabajo
  • Preguntas sobre presupuesto (deriva a contacto)
  • Datos de contacto: email, Instagram, WhatsApp
  • Información general de la agencia

Actualizar el comportamiento del chatbot

El "comportamiento" del chatbot está definido en el system prompt del archivo netlify/functions/chat.js. Es un texto en inglés que describe a Claude cómo debe responder.

Para modificarlo, editá el bloque que empieza con const SYSTEM_PROMPT = (lang) =>.

Costos del chatbot

Modelo usadoCosto aproximadoLímite por consulta
claude-haiku-4-5~$0.0003 por conversación300 tokens de respuesta

Es el modelo más económico de Anthropic. Una agencia con uso moderado (500 consultas/mes) gastará aproximadamente $0.15 USD/mes.

El chatbot no responde — checklist

SíntomaCausa probableSolución
Responde "Lo siento, hubo un problema"API Key incorrecta o ausenteVerificar variable en Netlify
No aparece el botón de chatError de JS en la páginaAbrir consola del navegador (F12)
Demora más de 10 segundosCold start de la función serverlessNormal en el primer uso del día
Responde en el idioma incorrectoBug en detección de idiomaReportar al equipo técnico
Privacidad Los mensajes del chat se envían a la API de Anthropic para generar respuestas. No se almacenan en ninguna base de datos del sitio. El historial de conversación se mantiene solo durante la sesión activa del navegador.

07

Logos, imágenes y fuentes

Estructura de la carpeta assets

assets/
├── logo/
│   ├── logo-icon.png      # Ícono de nube con anteojos (nav + favicon)
│   └── logo-blue.jpg      # Logo completo (Open Graph)
└── fonts/
    ├── Sniglet-ExtraBold.ttf   # Tipografía display (títulos)
    ├── Sniglet-Regular.ttf
    └── SourceSerif4-VariableFont_opsz,wght.ttf

Reemplazar el logo

1
Guardá el nuevo logo en assets/logo/ con el mismo nombre de archivo, o cambiá las referencias en el HTML si usás un nombre diferente.
2
El logo aparece en: la barra de navegación (.nav-logo-img), el hero (.hero-logo-float) y el footer (.footer-logo-img).
3
Para el favicon, reemplazá logo-icon.png con una imagen cuadrada de al menos 32×32px.

Agregar imágenes a proyectos

Guardá las imágenes en assets/projects/ (carpeta a crear). Tamaño recomendado: 1400×800px, formato JPG o WebP para mejor rendimiento.

Optimización Antes de subir imágenes, comprimilas en squoosh.app. Esto mejora la velocidad de carga del sitio, que impacta directamente en el SEO y la experiencia del usuario.

Cambiar colores de marca

Los colores están definidos como variables CSS al inicio del <style>:

:root {
  --blue:   #1F67B0;   /* Azul principal */
  --navy:   #0D1B2A;   /* Fondo oscuro */
  --accent: #00D4FF;   /* Cian brillante (acentos) */
  --white:  #F8FAFF;   /* Blanco ligeramente azulado */
}

Cambiar cualquiera de estas variables actualiza automáticamente todos los elementos que las usan.
